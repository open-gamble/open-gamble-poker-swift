# OpenGamblePoker

A Texas Hold'em poker game engine written in Swift. It models a real-world poker table as a state machine and can be used to serve hold'em games for real players.

Chip amounts only support integers. Treat the amounts as cents and do the conversion in the UI layer if you want to support decimal numbers.

## Acknowledgement

This library is a Swift port of the TypeScript [poker-ts](https://github.com/claudijo/poker-ts) written by [Claudijo](https://github.com/claudijo), which itself ports the [C++ poker library](https://github.com/JankoDedic/poker) designed by Janko Dedic. This project is a port of that engine into Swift. Note that minor differences in the API might exist.

## Installation

### Swift Package Manager

Add the package to your project with the git URL `https://github.com/open-gamble/open-gamble-poker-swift` (from version `1.0.0`), then import the `OpenGamblePoker` product:

```swift
import OpenGamblePoker
```

The package targets iOS 15+ and macOS 12+.

### XcodeGen

Open `OpenGamblePoker.xcodeproj` (generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`) and add `OpenGamblePoker` as a dependency, or regenerate the project yourself:

```sh
xcodegen generate
```

The project targets iOS and macOS; tests run on macOS.

## Example usage

The public API is the `Poker.Table` class — a state machine representing a poker table.

```swift
import OpenGamblePoker

let table = Poker.Table(forcedBets: Poker.ForcedBets(smallBlind: 50, bigBlind: 100))

table.sitDown(0, 1000) // seat a player at seat 0 with a 1000-chip buy-in
table.sitDown(2, 1500) // seat a player at seat 2 with a 1500-chip buy-in
table.sitDown(5, 1700) // seat a player at seat 5 with a 1700-chip buy-in

table.startHand()

while table.isHandInProgress() {
    while table.isBettingRoundInProgress() {
        let seatIndex = table.playerToAct()

        // Get `action` and possibly `betSize` in some way
        let (action, betSize) = getPlayerActionSomehow(seatIndex)

        table.actionTaken(action, betSize: betSize)
    }

    table.endBettingRound()

    if table.areBettingRoundsCompleted() {
        table.showdown()
    }
}

// 🎉 Congrats to the `table.winners()` 🎉
```

## API

### Custom types and enums

```swift
Poker.Card          // { rank: Poker.Card.Rank, suit: Poker.Card.Suit }
Poker.Card.Rank     // .two… .nine, .ten, .jack, .queen, .king, .ace
Poker.Card.Suit     // .clubs, .diamonds, .hearts, .spades
Poker.Action        // .fold, .check, .call, .bet, .raise
Poker.AutomaticAction // .fold, .checkFold, .check, .call, .callAny, .allIn
Poker.Seat          // { totalChips, stack, betSize }
Poker.LegalActions  // { actions: [Poker.Action], chipRange: ChipRange? }
Poker.ForcedBets    // { ante, bigBlind, smallBlind }
Poker.Winner        // { seatIndex, hand: Poker.HandInfo, holeCards: [Poker.Card] }
HandRanking         // .highCard … .royalFlush (Int raw values 0…9)
ChipRange           // { min, max }
SeatIndex           // Int
```

### `Poker.Table(forcedBets:numSeats:)`

Creates a poker table. `forcedBets` takes `smallBlind`, `bigBlind`, and an optional `ante`. `numSeats` defaults to 9.

### Player / hand lifecycle

- `sitDown(_ seat: SeatIndex, _ buyIn: Chips)` — seat a player. (Given seat must not be occupied.)
- `standUp(_ seat: SeatIndex)` — remove a player. (Given seat must be occupied.)
- `startHand(seat: SeatIndex? = nil)` — collect ante, place blinds, deal cards. (No hand in progress and ≥ 2 players seated.) Optionally set the dealer button; an invalid seat places the button at the first hand player.
- `endBettingRound()` — collect bets and form pots. (Betting round must not be in progress and rounds must not be completed.)
- `showdown()` — evaluate hands and pay winners. (Betting round must not be in progress and rounds must be completed.)

### State queries

- `playerToAct() -> SeatIndex` — seat of the player to act. (Betting round must be in progress.)
- `button() -> SeatIndex` — dealer button seat. (Hand must be in progress.)
- `seats() -> [Seat?]` — state of players seated at the table.
- `handPlayers() -> [Seat?]` — state of players in the current hand. (Hand must be in progress.)
- `numActivePlayers() -> Int` — active players in the current hand. (Hand must be in progress.)
- `pots() -> [Pot]` — current pots (use before `showdown()` to detect a single eligible player).
- `forcedBets() -> Poker.ForcedBets` — current bet structure.
- `setForcedBets(_:)` — modify the bet structure. (Hand must not be in progress.)
- `numSeats() -> Int` — number of seats.
- `isHandInProgress() -> Bool`
- `isBettingRoundInProgress() -> Bool` — (Hand must be in progress.)
- `areBettingRoundsCompleted() -> Bool` — (Hand must be in progress.)
- `roundOfBetting() -> RoundOfBetting` — `.preflop`, `.flop`, `.turn`, or `.river`. (Hand must be in progress.)
- `communityCards() -> [Poker.Card]` — community cards for the active hand. (Hand must be in progress.)
- `holeCards() -> [[Poker.Card]?]` — hole cards for the active hand. (Hand must be in progress or showdown must have ended.)
- `winners() -> [[Poker.Winner]]` — winners for each pot after showdown. (Hand must not be in progress.)

### Acting

- `legalActions() -> Poker.LegalActions` — legal actions for the player to act. (Betting round must be in progress.)
- `actionTaken(_ action: Poker.Action, betSize: Chips = 0)` — the player to act has taken an action. (Betting round must be in progress.)

### Automatic actions

- `automaticActions() -> [Poker.AutomaticAction?]` — toggled automatic actions. (Hand must be in progress.)
- `canSetAutomaticActions(_ seat: SeatIndex) -> Bool` — whether the player can set an automatic action. (Betting round must be in progress.)
- `legalAutomaticActions(_ seat: SeatIndex) -> [Poker.AutomaticAction]` — legal automatic actions for a player. (Player must be allowed to set automatic actions.)
- `setAutomaticAction(_ seat: SeatIndex, _ action: Poker.AutomaticAction?)` — set a player's automatic action. (Player must be allowed to set it and must not be the player to act.)
